# Welcome to LearnPDXSL

## Goal

This is LearnD3D11, a guide aimed at anyone trying to learn the Paradox Shading Language 
used in games such as HOI4. This guide explains the basic usage of PDXSL 
and shader programming, without requiring any previous experience with shaders.

## Disclaimer

I'm just a college student and I do this in my free time. This project is also still a work in progress; 
so some content may be missing or faulty. If you find typos, bugs or have questions, please open an issue or PR.
